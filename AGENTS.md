# Agent context — crafting-computer-chess

This repository is for studying computer chess. Learn by building from first principles.

Principles for any agent working here:

- Prefer simple, readable implementations before optimized ones. Code should help explain the underlying concept, not obscure it.
- Use established computer-chess terminology.
- Prefer authoritative references and primary sources.
- Keep experiments reproducible.
- Performance claims require measurements.
- Clearly distinguish established knowledge, hypotheses, observations, and conclusions — don't blend them.
- Avoid unnecessary frameworks, dependencies, abstractions, and production architecture.
- Do not turn this repository into a generic chess application.
- Add structure only when actual study requires it — no premature scaffolding.
- Depth of understanding is more important than covering many topics.
